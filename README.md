# React + Vite

## Run the app

Open a terminal in this project folder (`Desktop\node\node`) and run:

```powershell
npm install
npm run dev
```

Open the local URL printed by Vite.

To run the production build or lint checks:

```powershell
npm run build
npm run lint
```

If you are starting from `Desktop\node`, enter the project folder first:

```powershell
cd node
```

To initialize shadcn/ui in this project, use the correctly spelled package name:

```powershell
npx shadcn@latest init
```
